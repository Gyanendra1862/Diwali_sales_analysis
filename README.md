#  Diwali Sales Analysis using Python

##  Project Overview
This project performs Exploratory Data Analysis (EDA) on Diwali sales data to understand customer purchasing behavior during the festive season.

---

##  Objectives
- Analyze customer demographics and purchasing patterns
- Identify high-revenue states and product categories
- Perform customer segmentation
- Conduct hypothesis testing
- Generate business insights

---

##  Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

---

## Key Insights
- High-value customers contribute significantly to total revenue.
- Customers aged 26–35 years show strong purchasing behavior.
- Food and Clothing categories generate maximum sales.
- Marital status does not significantly impact spending behavior.
